## 文案与画面

故事来自项目发起者的讲述，经整理用于公开表达。画面采用暖纸色、蓝灰和橙色光线，以手绘生活场景串起故事。插画由 Codex 内置 imagegen 生成，表现的是想象中的场景，不是发起者、真实用户或其住所的照片。

这组图着重讲项目为什么出现。使用机制单独写在[主 README](../../README.md)，没有放进海报做操作教学，也没有把任何一种生活方式写成标准答案。

图片未使用应用截图、卫星影像或评分角色作为参考素材。网站本身的地图和角色来源仍见[特别声明](https://oneday.love/sources)。[最终提示词集](prompts.md)保留在此目录，便于后续修改与重建。
